# CodeAlpha Python Programming Internship

This repository contains all the Python projects completed as part of the
CodeAlpha Python Programming Internship program.

## 📁 Projects

### ✅ Task 1 — Hangman Game
A text-based Hangman game where the player guesses a hidden word one letter
at a time. Includes ASCII art, input validation, and a play-again option.
**Concepts:** `random`, `while loop`, `if-else`, `strings`, `sets`

### ✅ Task 2 — Stock Portfolio Tracker
A console app that lets users build a stock portfolio using hardcoded prices.
Displays a formatted summary and saves results to `.csv` and `.txt` files.
**Concepts:** `dictionary`, `input/output`, `arithmetic`, `file handling`

### ✅ Task 3 — Task Automation Scripts
Three automation utilities in one menu-driven script:
- Move `.jpg` files between folders
- Extract email addresses from a `.txt` file using regex
- Scrape a webpage title and save it with a timestamp
**Concepts:** `os`, `shutil`, `re`, `requests`, `file handling`

### ✅ Task 4 — Basic Chatbot
A rule-based chatbot (CodeBot) that responds to greetings, questions, jokes,
time/date queries, and more using regex pattern matching.
**Concepts:** `if-elif`, `functions`, `loops`, `re`, `input/output`

## 🚀 How to Run

```bash
# Clone the repo
git clone https://github.com/your-username/CodeAlpha_PythonInternship.git
cd CodeAlpha_PythonInternship

# Run any task
python Task1_Hangman/hangman.py
python Task2_StockPortfolioTracker/stock_portfolio_tracker.py
python Task3_TaskAutomation/task_automation.py
python Task4_Chatbot/chatbot.py
```

## 🛠 Requirements
- Python 3.10+
- `requests` library (Task 3 only) → `pip install requests`
